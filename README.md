# Angelo Gibbs: ANGELos

Portfolio site built as a retro pixel desktop. Plain HTML, CSS and JavaScript, no build step.

- `index.html`: the desktop (About Me, music player, Globe Tracker, Minesweeper and the rest)
- `work.html`: My Work, with each project's magazine, photos and credits
- `js/config.js`: all the content (text, links, songs, projects) lives here
- `assets/`: images, icons, fonts, music and PDFs (see `assets/README.md`)

Hosted on GitHub Pages straight from the `main` branch.
